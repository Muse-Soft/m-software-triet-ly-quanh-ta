# Triết Lý Quanh Ta

Trang giới thiệu kênh triết lý và phong thủy Triết Lý Quanh Ta: danh sách video, bài viết ngắn theo từng chủ đề, và mục liên hệ để khán giả theo dõi kênh.

> Lưu ý: đây là bản demo. Nội dung video, bài viết và liên kết trên trang hiện là dữ liệu mẫu, sẽ được thay bằng nội dung thật của kênh khi bàn giao.

## Demo trực tuyến

## Cách xem / chạy

Mở file `index.html` trong trình duyệt, hoặc chạy một máy chủ tĩnh tại thư mục gốc của repo, ví dụ:

```sh
python3 -m http.server 8000
```

rồi mở http://localhost:8000.
